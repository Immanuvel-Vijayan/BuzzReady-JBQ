BuzzReady — protected build (locked to immanuvel-vijayan.github.io)
==================================================================

This index.html is scrambled and will only run from your GitHub Pages
address. A copy opened from anywhere else shows a blank page.

To put it live, upload these TWO files to your repo, overwriting the old ones:
  - index.html   (the protected app)
  - sw.js        (version bumped so phones fetch the new copy)

In your repo (github.com/Immanuvel-Vijayan/BuzzReady-JBQ):
  1. Click "Add file" > "Upload files".
  2. Drag in this index.html and sw.js.
  3. "Commit changes".
  4. Wait ~1 minute, then open:
       https://immanuvel-vijayan.github.io/BuzzReady-JBQ/
     (If you had it open, close the tab and reopen, or hard-refresh, so the
      new service worker takes over.)

Keep editing from the readable version, not this one:
  This file cannot be edited by hand. When you want app changes, I change
  the readable master and rebuild this protected file for you.
