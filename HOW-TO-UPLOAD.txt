BuzzReady — encrypted + domain-locked build
============================================

This index.html is ENCRYPTED. It only decrypts and runs on your own site:
  https://immanuvel-vijayan.github.io/BuzzReady-JBQ/
A copy opened anywhere else (another site, or the file double-clicked from
your computer) shows a blank page - there is no readable app code to copy.

Upload these TWO files to your repo, overwriting the old ones:
  - index.html   (encrypted app)
  - sw.js        (version bumped so phones fetch the new copy)

Steps:
  1. In your repo, Add file > Upload files.
  2. Drag in this index.html and sw.js.
  3. Commit changes.
  4. Wait ~1 minute, then open (or hard-refresh):
       https://immanuvel-vijayan.github.io/BuzzReady-JBQ/

IMPORTANT:
  - It runs only over https (your GitHub Pages site is https - good) or on
    localhost. Double-clicking the file on your computer will NOT run it
    (no https) - that is expected.
  - Keep editing from the readable version. This file cannot be edited by
    hand; when you want changes, I rebuild this encrypted file for you.
